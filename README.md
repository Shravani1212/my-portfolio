## 💻 Getting Started

### Prerequisites

- Node.js (v16+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Shravani1212/my-portfolio.git
cd my-portfolio

# Install dependencies
npm install

# Start local development server
npm start
```

### Production Build

```bash
npm run build
```
